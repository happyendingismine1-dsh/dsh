# dsh

This repository is the working target of a **dsh-superagent** deployment
(<https://github.com/deepseek-ai/dsh-superagent-prototype>): a proactive coding
agent that listens to GitHub (and Feishu), turns authorized requests into
Tickets and executes each Ticket in its own session and directory.

## Usage

dsh-superagent targets this repository. Dispatch work to the
agent by commenting `@happyendingismine1-dsh <request>` on an Issue or by
mentioning the bot in the configured Feishu chat. All changes are submitted as
pull requests.
