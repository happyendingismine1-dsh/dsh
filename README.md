# dsh

This repository is the working target of a **dsh-superagent** deployment
(<https://github.com/deepseek-ai/dsh-superagent-prototype>): a proactive coding
agent that listens to GitHub (and Feishu), turns authorized requests into
Tickets and executes each Ticket in its own session and directory, usually
delivering a pull request.

Ask for work by commenting `@happyendingismine1-dsh <request>` on an Issue, or by
mentioning the bot in the configured Feishu chat.
